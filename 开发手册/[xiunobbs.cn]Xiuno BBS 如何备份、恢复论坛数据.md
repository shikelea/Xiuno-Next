# Xiuno BBS 备份恢复教程

## 1. 备份方法

### 1.1 数据库备份

**方法一：使用 phpMyAdmin**
1. 登录 phpMyAdmin
2. 选择论坛数据库
3. 点击「导出」选项卡
4. 选择「快速」导出方法
5. 格式选择「SQL」
6. 点击「执行」按钮下载备份文件

**方法二：使用命令行**
```bash
mysqldump -u 用户名 -p 数据库名 > xiuno_bbs_backup.sql
```

### 1.2 文件备份

**重要文件和目录**：
- `conf/` 目录 - 配置文件
- `upload/` 目录 - 上传的附件、头像等
- `plugin/` 目录 - 已安装的插件与主题

**备份方法**：
1. 使用 FTP 或文件管理器下载上述文件和目录
2. 或者使用命令行打包：
   - Linux 系统:"tar -czvf xiuno_bbs_backup.tar.gz ./*"
   - Windows 系统:使用压缩软件如 WinRAR 或 7-Zip 打包

## 2. 恢复方法

### 2.1 环境准备

1. 确保 PHP 版本兼容（推荐 PHP 7.2+ 或 PHP 8.0+）
2. 确保 MySQL 版本兼容
3. 创建新的数据库和用户

###　2.2. 重新安装
按照安装步骤重新安装论坛，确保数据库连接信息正确。

### 2.3. 数据库恢复

**方法一：使用 phpMyAdmin**
1. 登录 phpMyAdmin
2. 选择目标数据库
3. 点击「导入」选项卡
4. 选择备份的 SQL 文件
5. 点击「执行」按钮

**方法二：使用命令行**
```bash
mysql -u 用户名 -p 数据库名 < xiuno_bbs_backup.sql
```

### 2.4 文件恢复

1. 将备份的文件和目录上传到服务器对应位置
2. 确保文件权限正确：
   - 目录权限：755
   - 文件权限：644
   - `upload/` 目录及其子目录需要可写权限

### 2.5 清理缓存

删除 `tmp/` 目录下的所有文件（如果里面有文件的话）


## 4. 常见问题和解决方案

### 4.1 数据库连接失败

**症状**：访问论坛时提示数据库连接失败

**解决方案**：
- 必须先直接安装xiuno bbs再进行数据库的恢复
- 在安装过程中注意：
  - 检查数据库用户名和密码是否正确
  - 检查数据库服务器是否可访问
  - 检查数据库名是否正确
  - 检查表前缀是否匹配

### 4.2 附件无法访问

**症状**：论坛中的附件或头像无法显示

**解决方案**：
- 确保附件文件已正确上传（位于 `upload/` 目录下）

### 4.3 插件功能异常

**症状**：插件与主题无法正常工作

**解决方案**：
- 在后台重新安装插件
  - 进入后台
  - 进入插件部分
  - 点击卸载按钮
  - 点击安装按钮，重新安装插件

## 5. 注意事项

1. **备份前准备**：
   - 确保备份时论坛处于关闭状态，避免数据不一致
   - 备份前清理无效数据，减小备份文件大小

2. **恢复前准备**：
   - 确保目标服务器环境与原服务器兼容
   - 备份目标服务器上的现有数据，以防万一

3. **迁移后检查**：
   - 检查论坛基本功能是否正常
   - 检查附件是否可正常访问
   - 检查用户登录是否正常
   - 检查帖子和回复是否完整

4. **安全建议**：
   - 定期备份数据库和文件
   - 备份文件存储在安全的位置
   - 迁移过程中注意保护敏感信息
   - 完成迁移后更改管理员密码

5. **版本兼容性**：
   - 确保迁移前后使用相同或兼容的 Xiuno BBS 版本
   - 如果跨版本迁移，先在测试环境验证
